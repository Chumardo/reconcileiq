# Upwork portfolio entry

## Project title

ReconcileIQ | Transaction Reconciliation and Excel Audit

## Role

Python development, reconciliation rules, and audit reporting

## Project description

I built ReconcileIQ to compare transaction exports such as a ledger and a settlement file. In the local app, set matching keys and an amount tolerance, review discrepancies beside their source rows, and export a seven-sheet Excel audit. Repeated keys are set aside so they cannot multiply matches, and currency totals stay separate. The public demo uses 20,001 synthetic rows. This is a self-directed portfolio project.

## Skills and technologies

- **Suggested Upwork tags** · Python, SQL, Data Analysis, Data Cleaning, Microsoft Excel
- **Project tools** · DuckDB, pandas, Streamlit, Altair, openpyxl, Python `Decimal`, pytest

## Business value

Use this workflow to compare ledger, payment, or settlement extracts that share transaction keys. It gives a reviewer a list of discrepancies to investigate, shows the source rows behind each one, and produces a workbook colleagues can review with the same matching rules and currency totals.
